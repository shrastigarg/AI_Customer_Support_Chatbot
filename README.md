# 🤖 AI Customer Support Chatbot

A professional AI-powered Customer Support Chatbot built using Flask and SQLite. The application provides secure user authentication and an interactive chatbot interface for answering basic customer support queries.

## 🚀 Features

- 🔐 User Registration & Login
- 🔒 Secure Password Hashing
- 💾 SQLite Database
- 🤖 AI Chatbot
- 💬 Interactive Chat Interface
- 📱 Responsive Design
- 🎨 Clean and Modern UI
- ⚡ Flask Backend
- 🌐 HTML, CSS & JavaScript Frontend

## 🛠️ Tech Stack

- Python
- Flask
- Flask-Login
- Flask-SQLAlchemy
- SQLite
- HTML5
- CSS3
- JavaScript
