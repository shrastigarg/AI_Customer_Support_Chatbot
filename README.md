# 🤖 AI Customer Support Chatbot

A professional AI-powered Customer Support Chatbot built using Flask and SQLite. The application provides secure user authentication and an interactive chatbot interface for answering basic customer support queries.

## 🚀 Features

- 🔐 User Registration & Login
- 🔒 Secure Password Hashing
- 💾 SQLite Database
- 🤖 AI Chatbot
- 💬 Interactive Chat Interface
- 📱 Responsive Design
- 🎨 Clean and Modern UI
- ⚡ Flask Backend
- 🌐 HTML, CSS & JavaScript Frontend

## 🛠️ Tech Stack

- Python
- Flask
- Flask-Login
- Flask-SQLAlchemy
- SQLite
- HTML5
- CSS3
- JavaScript


## ⚙️ Installation

1. Clone the repository

bash
git clone <repository-link>


2. Install dependencies

bash
pip install -r requirements.txt


3. Run the application

bash
python app.py


4. Open your browser

http://127.0.0.1:5000
